Set up
Meaning: Prepare equipment, software, etc., for use
المعني: جهز معدات أو برامج الخ للاستخدام
Example: The technician SET UP the computer network perfectly.
مثال: جهز التقنيون شبكة كمبيوتر بشكل مثالي
Notes:
Separable [optional] قابل للفصل(اختياري)(المفعول به يوضع بين الفعل وحرف الجر)
