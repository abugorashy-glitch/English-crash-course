Run down
Meaning: Lose energy or power
المعني: افقد طاقة أو قوة
Example: You should only recharge the battery when it has fully RUN DOWN.
مثال: يجب عليك أن تعيد تعبئة البطارية لأنها فرغت بالكامل.
Notes:
Separable [optional] قابل للفصل(اختياري)(المفعول به يوضع بين الفعل وحرف الجر)
