Set up
Meaning: Provide someone with the money needed to live
المعني: زود شخص ما بالمال المطلوب لكي يعيش
Example: Winning the lottery SET them UP for life.
مثال: ربح القرعة زودهم بالمعيشة للابد.
Notes:
Separable [optional] قابل للفصل(اختياري)(المفعول به يوضع بين الفعل وحرف الجر)
